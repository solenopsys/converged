## Source Code

Converged is developed as a fully open platform. **The entire source code is available under the AGPL-3.0 license** and is hosted in a public repository:

[GitHub — Converged](https://github.com/solenopsys/converged?utm_source=chatgpt.com)

Open source means that users can not only run the platform, but also inspect how it works, audit its security, adapt it to their needs, and deploy it within their own infrastructure.

The repository contains the current implementation of the platform and shows how its **Services, Apps, runtimes, Surfaces, Workflows, storage, communications, deployment, and equipment adapters** are organized. This allows developers and companies to evaluate the platform before deployment and, when necessary, independently inspect or modify any part of it.

An open architecture also removes dependence on a closed vendor. Companies do not receive a black box: **the code is available for inspection, data can remain under their own control, and the platform can be deployed within their own infrastructure.**
